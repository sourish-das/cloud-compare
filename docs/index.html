OCI Compute — How Pricing Works

• OCPU model
OCI prices compute using OCPUs.
x86 (AMD/Intel): 1 OCPU = 2 vCPUs
Ampere ARM: 1 OCPU = 1 vCPU

• Flex shape billing
OCI Flex shapes bill CPU and memory separately:
Total Price = (OCPU/hr × rate) + (RAM GB/hr × rate)
This gives highly configurable instances.

• Processor selection
Auto: returns the cheapest instance across all processors
AMD: selects the latest AMD E‑series generation (e.g., E6)
Ampere: selects the latest ARM A‑series generation (e.g., A4)
Intel: selects the latest Standard3/Optimized3 generation
Then picks the cheapest shape within that generation.

• Windows note
Windows licensing is added per vCPU/hr.
Windows does not run on Ampere shapes.
